# V3.0.118 複数選択修正計画

**作成日時**: 2025-10-02 22:05  
**問題**: V3.0.115でも複数選択が動作していない（元々の設計問題）

---

## 🔍 根本原因の特定完了

### 問題のコード (MainWindow.xaml:490)
```xaml
<ListBox behaviors:V3AdvancedDragDropBehavior.IsDragSource="True"
         behaviors:V3AdvancedDragDropBehavior.IsDropTarget="True">
```

**問題点**: ListBoxレベルでBehaviorを適用すると、ListBoxの標準的なCtrl+クリック複数選択処理と干渉する

---

## ✅ 解決策: ListBoxItemレベルでのBehavior適用

### 変更方法

**現在 (MainWindow.xaml:481-493)**:
```xaml
<ListBox behaviors:V3AdvancedDragDropBehavior.IsDragSource="True"
         behaviors:V3AdvancedDragDropBehavior.IsDropTarget="True"
         behaviors:V3AdvancedDragDropBehavior.DragHandler="{Binding DragDropHandler}"
         behaviors:V3AdvancedDragDropBehavior.DropHandler="{Binding DragDropHandler}">
    <ListBox.ItemContainerStyle>
        <Style TargetType="ListBoxItem">
            ...
        </Style>
    </ListBox.ItemContainerStyle>
</ListBox>
```

**修正後**:
```xaml
<ListBox behaviors:V3AdvancedDragDropBehavior.IsDropTarget="True"
         behaviors:V3AdvancedDragDropBehavior.DropHandler="{Binding DragDropHandler}">
    <ListBox.ItemContainerStyle>
        <Style TargetType="ListBoxItem">
            <!-- 🆕 V3.0.118: ListBoxItemレベルでドラッグソース設定 -->
            <Setter Property="behaviors:V3AdvancedDragDropBehavior.IsDragSource" Value="True"/>
            <Setter Property="behaviors:V3AdvancedDragDropBehavior.DragHandler" Value="{Binding DataContext.DragDropHandler, RelativeSource={RelativeSource AncestorType=ListBox}}"/>
            ...
        </Style>
    </ListBox.ItemContainerStyle>
</ListBox>
```

### 変更点
1. **ListBoxから削除**:
   - `IsDragSource="True"`
   - `DragHandler` binding

2. **ItemContainerStyleに追加**:
   - `IsDragSource` Setter
   - `DragHandler` Setter (RelativeSourceで親のDataContextを参照)

3. **ListBoxに残す**:
   - `IsDropTarget="True"` (ドロップ先はListBox全体)
   - `DropHandler` binding

## 🎓 技術的背景

### なぜListBoxレベルのBehaviorが問題なのか

**WPFのイベントルーティング**:
```
ListBox.PreviewMouseLeftButtonDown (トンネリング)
  ↓
ListBoxItem.PreviewMouseLeftButtonDown
  ↓
ListBox内部の複数選択処理 (Ctrl/Shift検出)
  ↓
ListBoxItem.MouseLeftButtonDown (バブリング)
  ↓
ListBox.MouseLeftButtonDown
```

**ListBoxレベルでBehaviorをアタッチすると**:
- ListBox.MouseLeftButtonDownにハンドラー登録
- ListBoxの複数選択処理と**競合**
- 結果: Ctrl+クリックが正常動作しない

**ListBoxItemレベルでBehaviorをアタッチすると**:
- ListBoxItem.MouseLeftButtonDownにハンドラー登録
- ListBoxの複数選択処理と**独立**
- 結果: Ctrl+クリックが正常動作
