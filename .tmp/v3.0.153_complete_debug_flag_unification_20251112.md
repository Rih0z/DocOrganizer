## 📊 フラグの使い分け

### #if DEBUG
**用途**: Visual Studioのビルド構成（Debug/Release）に連動

**対象コード**:
- `System.Diagnostics.Debug.WriteLine`
- 開発時のみ必要なデバッグ出力

**V3.0.153での適用**:
- V3DragDropInfo.cs: 17箇所
- App.xaml.cs: 3箇所

**合計**: 20箇所

---

### #if ENABLE_LOGGING
**用途**: カスタムログシステムの有効/無効制御

**対象コード**:
- DebugLogger クラスのメソッド
- ファイル書き込みを伴うログ処理
- パフォーマンス監視レポート

**V3.0.153での適用**:
- PdfPerformanceMonitor.cs: 1箇所（GenerateMonthlyReportAsync）
- SimpleDebugTest.cs: 1箇所（クラス全体）

**合計**: 2箇所

**V3.0.152での適用（既存）**:
- DebugLogger.cs: 全メソッド・プロパティ

## 🎯 統一フラグ管理の確立

### 原則1: デバッグ出力は #if DEBUG
```csharp
#if DEBUG
System.Diagnostics.Debug.WriteLine("デバッグ情報");
#endif
```

### 原則2: ファイルI/Oログは #if ENABLE_LOGGING
```csharp
#if ENABLE_LOGGING
await File.WriteAllTextAsync(logPath, content);
#endif
```

### 原則3: クラス全体のガード
```csharp
#if ENABLE_LOGGING
public static class DebugHelper
{
    // クラス全体がリリース版で除外される
}
#endif
```
