# DocOrganizer V3.0.025 Beta Test Guide

**Test Period**: 2 weeks from distribution  
**Version**: V3.0.025-BETA  
**New Feature**: PDF Provider - Display PDF thumbnails and previews

---

## 🎯 What's New in V3.0.025

### 📄 **PDF Display Feature**
- **NEW**: Drag & drop PDF files to see actual content thumbnails
- **NEW**: PDF preview display on the right side
- **Enhancement**: Same interface as images (HEIC/JPG/PNG) now works with PDFs

### 🔧 **How It Works**
1. Drag PDF file(s) into DocOrganizer window
2. Thumbnails with actual PDF content appear on the left
3. Click any thumbnail to see full preview on the right
4. All existing functions work the same (rotate, combine, export)

---

## 🧪 Testing Instructions

### 📋 **Basic Functionality Test**
1. **Launch DocOrganizer**: Double-click DocOrganizer.exe (located in release/ folder)
2. **Test PDF Display**: 
   - Drag a PDF file into the main window
   - Verify thumbnail shows actual PDF content (not blank/placeholder)
   - Click thumbnail to verify preview appears on the right
   - Test with multiple PDF files
3. **Test Performance**:
   - Note how long thumbnails take to generate
   - Monitor application responsiveness
   - Check memory usage (Task Manager)

### 📊 **Advanced Testing** (Optional)
- Test with various PDF sizes (small 1MB vs large 50MB+)
- Test with password-protected PDFs
- Test combining PDFs with images
- Test with corrupted or unusual PDF files
- Test extended use (multiple sessions)

### 🐛 **Problem Reporting**
If you encounter any issues:
1. **Screenshot**: Capture what happened
2. **File Info**: Note the PDF file size/type that caused issues
3. **Performance**: Note if application became slow/unresponsive
4. **Error Messages**: Copy any error messages that appear
