# PDF保存機能使用ガイド

## 概要
DocOrganizer V3.0.005では、画像ファイルをPDFとして保存する高品質なPDF出力機能を提供しています。サムネイルプレビューと完全に同じ向きで画像が出力されます。

## 対応ファイル形式
- **PDF**: 既存PDFファイル
- **画像形式**: HEIC, JPG, JPEG, PNG
- **自動変換**: 画像ファイルは自動的にPDFページに変換されます

## 基本的な使用方法

### 1. ファイルの読み込み
1. **ドラッグ&ドロップ**: ファイルを画面中央にドラッグ&ドロップ
2. **メニューから**: `ファイル` → `PDF・画像ファイルを開く`
3. **ショートカット**: `Ctrl+O`

### 2. PDF出力の実行
1. **PDF出力ボタン**: ツールバーの「📄 PDF出力」ボタンをクリック
2. **画質選択**: 事前にコンボボックスで画質を選択可能
3. **自動保存**: `release/output/` フォルダに日時付きで自動保存

## PDF出力機能の特徴

### 🎯 画像向き自動補正
- **EXIF情報対応**: 画像のEXIF Orientationを自動読み取り
- **向き統一**: サムネイルプレビューとPDF出力で完全同一の向き
- **手動回転対応**: 右回転・左回転した結果もPDFに正確反映

### 🔧 高品質画像処理
- **ImageSharp使用**: 最新の画像処理ライブラリによる高品質変換
- **EXIF除去**: PDF内で重複回転を防ぐメタデータ除去
- **アスペクト比保持**: 元画像の縦横比を維持

### 📄 PDFページ設定
- **ページサイズ**: A4サイズ (595×842ポイント)
- **配置**: 画像を中央配置で最大化表示
- **品質**: 選択した画質設定に基づく最適化

## 画質設定オプション

### 利用可能な画質レベル
1. **最高画質**: 原画サイズ維持、品質100%
2. **高画質**: 最大2048×2048、品質95%
3. **中画質** (推奨): 最大1920×1440、品質85%
4. **標準画質**: 最大1280×960、品質75%
5. **低画質**: 最大800×600、品質60%

### 画質選択の目安
- **文書保存用**: 中画質 (ファイルサイズと品質のバランス)
- **印刷用**: 高画質または最高画質
- **Web共有用**: 標準画質または低画質

## 出力ファイル仕様

### ファイル命名規則
```
document_YYYYMMDD_HHMMSS.pdf
例: document_20250819_163951.pdf
```

### 出力先フォルダ
```
C:\Users\[ユーザー名]\github\DocOrganizer\release\output\
```

### PDFメタデータ
- **タイトル**: ファイル名（拡張子なし）
- **作成者**: DocOrganizer V3.0
- **説明**: Generated by DocOrganizer
- **作成日時**: PDF生成時刻

## 操作手順（詳細）

### Step 1: ファイル準備
1. 対応形式のファイルを用意
2. DocOrganizer V3.0.005を起動
3. 画面中央の「ここにドラッグ&ドロップ」エリアを確認

### Step 2: ファイル読み込み
1. ファイルをドラッグ&ドロップ
2. サムネイル一覧（左パネル）に表示確認
3. プレビュー（右パネル）で内容確認

### Step 3: 編集（必要に応じて）
1. **ページ順序**: ドラッグ&ドロップで並び替え
2. **回転**: 左回転・右回転ボタン使用
3. **削除**: 不要ページを選択してDeleteキー
4. **自動回転**: 📖ボタンで全ページ文字向き自動補正

### Step 4: 画質設定
1. ツールバーの画質選択コンボボックスを確認
2. 用途に応じて画質レベルを選択
3. デフォルトは「中画質」（推奨）

### Step 5: PDF出力
1. 「📄 PDF出力」ボタンをクリック
2. 進行状況をステータスバーで確認
3. 完了メッセージの確認

### Step 6: 出力確認
1. `release/output/`フォルダを開く
2. 生成されたPDFファイルを確認
3. PDFビューアーで内容確認

## トラブルシューティング

### PDF出力ボタンが無効な場合
- **原因**: ファイルが読み込まれていない
- **解決**: 対応形式のファイルを読み込み直し

### 画像の向きが違う場合
- **V3.0.005で解決済み**: AutoOrient()による自動補正実装
- **手動調整**: 右回転・左回転ボタンで調整可能

### ファイルサイズが大きすぎる場合
- **解決**: 画質設定を「標準画質」または「低画質」に変更
- **バランス重視**: 「中画質」が推奨設定

### 出力エラーが発生した場合
1. **ファイル形式確認**: 対応形式かチェック
2. **ファイル破損確認**: 他のアプリで開けるかテスト
3. **再起動**: DocOrganizerを再起動して再試行

## 技術仕様

### 使用ライブラリ
- **ImageSharp**: 高品質画像処理
- **PDFsharp**: PDF生成エンジン
- **WPF**: ユーザーインターフェース

### 処理フロー
```
画像読み込み → EXIF補正 → 手動回転適用 → 品質調整 → PDF作成 → ファイル保存
```

### 対応EXIF Orientation値
- 1: 正常（0度）
- 3: 180度回転
- 6: 90度右回転（時計回り）
- 8: 90度左回転（反時計回り）
