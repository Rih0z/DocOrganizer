## 🔬 V3.0.134の核心修正

### 根本原因

**問題**: `IsDragSource="True"`が**ListBox全体**にアタッチされていた

```xml
<!-- V3.0.133まで（問題あり） -->
<ListBox behaviors:V3AdvancedDragDropBehavior.IsDragSource="True">
    <!-- ListBox全体でマウスイベント発火 -->
    <!-- ScrollBarクリックもイベント検出 → スクロール不可 -->
</ListBox>
```

**結果**:
- ScrollBarクリック時もOnPreviewMouseLeftButtonDownが発火
- どんな判定ロジック（IsScrollBarClick、ListBoxItem判定等）でも回避不可
- **構造的な問題**

---

### 解決策

**修正**: IsDragSourceを**ListBoxItemのみ**にアタッチ

```xml
<!-- V3.0.134（解決） -->
<ListBox behaviors:V3AdvancedDragDropBehavior.IsDropTarget="True"
         behaviors:V3AdvancedDragDropBehavior.DropHandler="{Binding DragDropHandler}">
    <!-- ListBoxにはDropTargetのみ、IsDragSourceなし -->

    <ListBox.ItemContainerStyle>
        <Style TargetType="ListBoxItem">
            <!-- ✅ V3.0.134: IsDragSourceをListBoxItemレベルに移動 -->
            <Setter Property="behaviors:V3AdvancedDragDropBehavior.IsDragSource" Value="True"/>
            <Setter Property="behaviors:V3AdvancedDragDropBehavior.DragHandler"
                    Value="{Binding DataContext.DragDropHandler, RelativeSource={RelativeSource AncestorType=ListBox}}"/>
        </Style>
    </ListBox.ItemContainerStyle>
</ListBox>
```

**効果**:
- ScrollBarにはIsDragSourceがアタッチされない
- ScrollBarクリック時にイベントが発火しない
- **ScrollBarとドラッグ&ドロップが完全分離**
- **構造的に問題を解決**

## 🔧 技術的詳細

### WPF添付プロパティの適用範囲

**重要な発見**:

```xml
<!-- パターン1: 親要素に添付（V3.0.133まで） -->
<ListBox behaviors:IsDragSource="True">
    <!-- ListBox全体のイベントにBehaviorが適用 -->
    <!-- ScrollBar、ListBoxItem、余白、全てに影響 ❌ -->
</ListBox>

<!-- パターン2: 子要素に添付（V3.0.134） -->
<ListBox>
    <ListBox.ItemContainerStyle>
        <Style TargetType="ListBoxItem">
            <Setter Property="behaviors:IsDragSource" Value="True"/>
            <!-- 各ListBoxItemのみにBehaviorが適用 ✅ -->
            <!-- ScrollBarには一切影響しない ✅ -->
        </Style>
    </ListBox.ItemContainerStyle>
</ListBox>
```

### イベントの発火

**V3.0.133まで**:
```
ScrollBarクリック
→ ListBoxのPreviewMouseLeftButtonDown発火
→ OnPreviewMouseLeftButtonDown呼ばれる
→ 判定ロジックでreturn
→ しかし何らかの干渉でスクロール不可 ❌
```

**V3.0.134**:
```
ScrollBarクリック
→ ScrollBarにはIsDragSourceなし
→ OnPreviewMouseLeftButtonDownは呼ばれない
→ ScrollBarの標準動作のみ実行
→ 正常にスクロール ✅
```

## 💡 学んだ教訓

### 問題解決のアプローチ

**失敗したアプローチ（V3.0.130-V3.0.133）**:
- ❌ イベントハンドラー内で複雑な判定ロジックを追加
- ❌ 対症療法

**成功したアプローチ（V3.0.134）**:
- ✅ Behaviorのアタッチ先を変更
- ✅ 構造的な根本解決

### WPFの理解

**重要な知識**:
1. 添付プロパティは**その要素にのみ**適用される
2. ItemContainerStyleで設定すれば**各ListBoxItem**に個別適用
3. **親要素と子要素を区別**することが重要
