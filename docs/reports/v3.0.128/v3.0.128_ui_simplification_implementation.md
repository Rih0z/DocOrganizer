## 📋 実装概要

### 目的
不要なメニューとボタンを削除し、UIをシンプルで直感的にする。全ての機能はキーボードショートカットとツールバーアイコンで利用可能。

### 削除対象
1. **メニューバー**: ファイル・編集・ページ・文書・テストメニュー
2. **ツールバー**: 自動回転ボタン

---

## 🗑️ 削除されたメニュー

### 1. ファイルメニュー
**削除された項目**:
- 新規作成（Ctrl+N）
- 開く（Ctrl+O）
- 保存（Ctrl+S）
- 名前を付けて保存（Ctrl+Shift+S）
- 終了（Ctrl+W / Ctrl+Q / Alt+F4）

**機能保持方法**:
- 全てのキーボードショートカットは完全保持
- `Window.InputBindings`による操作は全て有効

### 2. 編集メニュー
**削除された項目**:
- 元に戻す（Ctrl+Z）
- やり直し（Ctrl+Y）
- 全て選択（Ctrl+A）
- 選択解除（Ctrl+Shift+A）

**機能保持方法**:
- キーボードショートカット完全保持

### 3. ページメニュー
**削除された項目**:
- 左回転（Ctrl+L / Alt+Left）
- 右回転（Ctrl+R / Alt+Right）
- 上に移動（Ctrl+B / Alt+Up）
- 下に移動（Ctrl+F / Alt+Down）
- 削除（Delete / Ctrl+D）

**機能保持方法**:
- キーボードショートカット完全保持
- ツールバーアイコンで直感的に操作可能

### 4. 文書メニュー
**削除された項目**:
- PDF分割（Ctrl+Shift+P）
- PDF結合（Ctrl+Shift+M）

**機能保持方法**:
- キーボードショートカット完全保持
- PDF編集メニューで利用可能（PDF読み込み時のみ表示）

### 5. テストメニュー
**削除された項目**:
- デバッグ用の全メニュー

**理由**:
- 本番環境では不要

---

## 🛠️ 削除されたツールバーボタン

### 自動回転ボタン
**理由**:
- 使用頻度が低い
- 手動回転で十分対応可能
- UIをシンプルに保つため

## 🎯 UI改善効果

### Before (V3.0.127以前)
- ❌ メニューバーが複雑（ファイル・編集・ページ・文書・表示・テスト・ヘルプ）
- ❌ 初心者にとって選択肢が多すぎる
- ❌ どの機能をどこから実行するか迷いやすい

### After (V3.0.128)
- ✅ メニューバーがシンプル（PDF編集・表示・ヘルプのみ）
- ✅ ツールバーアイコンで直感的に操作
- ✅ キーボードショートカットで上級者も満足
- ✅ 初心者にも分かりやすい

## 🔑 保持されている機能

### 完全に保持
1. **全てのキーボードショートカット**
   - `Window.InputBindings`で定義
   - メニューが削除されても動作継続

2. **全てのコマンドバインディング**
   - ViewModelのコマンドは削除していない
   - ツールバーから実行可能

3. **ツールバーアイコン**
   - 回転（↺、↻）
   - 削除（🗑）
   - 移動（▲、▼）
   - ズーム（🔍+、🔍-）
   - PDF出力（📄）
