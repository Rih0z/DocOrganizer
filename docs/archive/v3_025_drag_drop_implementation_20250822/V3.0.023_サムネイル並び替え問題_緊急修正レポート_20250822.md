# V3.0.023 サムネイル並び替え問題 緊急修正レポート

## 根本原因分析

### V3.0.022での問題
- **外部ファイルドロップ**: ✅ 復旧成功
- **サムネイル並び替え**: ❌ 依然として動作せず

### 真の根本原因発見: V3DropInfoの誤判定

**V3DropInfo.cs コンストラクタの問題**:
```csharp
// 🔴 問題: サムネイルドラッグでもFileDrop判定される
if (dragEventArgs.Data.GetDataPresent(DataFormats.FileDrop))
{
    FilePaths = (string[])dragEventArgs.Data.GetData(DataFormats.FileDrop);
    Data = FilePaths;  // ← サムネイルでも String[] が設定される
}
else
{
    Data = dragEventArgs.Data;  // ← この分岐が実行されない
}
```

### 問題の流れ
1. **サムネイルドラッグ開始**: `StartDragAsync`で`DataFormats.Text`にGUIDを設定
2. **V3DropInfo作成時**: `DataFormats.FileDrop`が存在すると誤判定
3. **Data設定**: `Data = String[]` (本来は `Data = IDataObject` であるべき)
4. **DropAsync実行**: `String[]`なので外部ファイルドロップとして処理
5. **結果**: サムネイル並び替えが実行されない

## V3.0.023修正計画

### 修正対象
- **ファイル**: `src/DocOrganizer.UI/Models/V3/V3DragDropInfo.cs`
- **メソッド**: コンストラクタのデータ判定ロジック

### 修正方針
サムネイルドラッグと外部ファイルドロップを正確に区別：
1. **Text形式優先判定**: `DataFormats.Text`が存在する場合はサムネイルドラッグ
2. **FileDrop判定**: `DataFormats.Text`が存在しない場合のみファイルドロップ

### 修正コード
```csharp
// 🎯 V3.0.023: サムネイルドラッグと外部ファイルドロップの正確な区別
if (dragEventArgs.Data.GetDataPresent(DataFormats.Text))
{
    // サムネイルドラッグの場合
    Data = dragEventArgs.Data;  // IDataObject を保持
    FilePaths = new string[0];
}
else if (dragEventArgs.Data.GetDataPresent(DataFormats.FileDrop))
{
    // 外部ファイルドロップの場合
    FilePaths = (string[])dragEventArgs.Data.GetData(DataFormats.FileDrop);
    Data = FilePaths;  // String[] を設定
}
else
{
    // その他のデータ
    Data = dragEventArgs.Data;
    FilePaths = new string[0];
}
```
