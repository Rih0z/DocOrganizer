#### ❌ 根本的問題箇所の特定

**問題1: イベント重複実行**
- 現象: 同一ドロップで2回のDropAsync実行
- 原因: 複数要素（MainWindow + ListBox）がドロップターゲット登録
- 影響: InsertIndex計算の不整合（-1 と 3）

**問題2: InsertIndex計算エラー**
- 現象: CalculateInsertIndex()が-1を返す
- 原因: V3DropInfo.CalculateInsertIndex()のListBox検索失敗
- 影響: 並び替え位置の特定不能

**問題3: MainCompositeViewModelの並び替え処理未実行**
- 現象: PageReorderRequestedイベント発火後、実際の並び替えなし
- 原因: MainCompositeViewModelのイベントリスナー未接続または処理失敗
- 影響: UI上の順序変更が反映されない

```csharp
// V3DropInfo.cs - CalculateInsertIndex改良
private int CalculateInsertIndex(FrameworkElement targetElement, Point dropPosition)
{
    // より堅牢なListBox検索ロジック
    var listBox = FindParentListBox(targetElement) ?? 
                  VisualTreeHelper.FindAncestor<ListBox>(targetElement);
    
    if (listBox?.ItemContainerGenerator == null) return 0;
    
    // 改良された位置計算
    for (int i = 0; i < listBox.Items.Count; i++)
    {
        var container = listBox.ItemContainerGenerator.ContainerFromIndex(i);
        if (container == null) continue;
        
        var itemBounds = container.TransformToAncestor(listBox)
                                .TransformBounds(new Rect(container.RenderSize));
        
        if (dropPosition.Y < itemBounds.Top + itemBounds.Height / 2)
            return i;
    }
    return listBox.Items.Count;
}
```
