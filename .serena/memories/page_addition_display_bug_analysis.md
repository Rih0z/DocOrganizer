# ページ追加時の表示バグ分析 (2025-01-19)

## 問題の症状
1. 画像を内包すると（ページ移動操作をすると）サムネイル表示がおかしくなる
2. 追加したい上の画像がサムネイルとして一瞬表示された後、全てのサムネイルがなくなる

## デバッグログから判明した異常な動作
```
[2025-08-19 07:22:04.222] [LoadPagesAsync] 完全リロードモード - 全ページクリア
[2025-08-19 07:22:04.225] [OnFilesAddedToDocument] 既存ドキュメントへのファイル追加イベント受信
[2025-08-19 07:22:04.230] [LoadPagesAsync] 増分更新モード - 既存0ページ保持
```

**重要な発見**：
- LoadPagesAsyncが2回呼ばれている
- 最初は「完全リロードモード」で全ページをクリア
- 次に「増分更新モード」で既存0ページ保持（既にクリアされているため）

## 推測される原因
1. **イベントの重複発火**
   - FilesAddedToDocumentイベントが複数回発火している可能性
   - または別のイベントハンドラーからもLoadPagesAsyncが呼ばれている

2. **競合状態（Race Condition）**
   - 非同期処理が適切に管理されていない
   - 複数のイベントハンドラーが同時に実行されている

## 調査すべき箇所
1. DragDropHandlerViewModelのHandleFilesDropAsync
2. MainCompositeViewModelのイベントハンドラー（特にOnFilesAddedToDocument）
3. LoadPagesAsyncの呼び出し元すべて
